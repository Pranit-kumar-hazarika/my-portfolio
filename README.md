# Pranit Kumar Hazarika

## Run locally

```bash
python -m http.server 8000
```

Open http://localhost:8000.

The contact form is handled by Netlify Forms when deployed to Netlify. To receive email alerts for new inquiries, configure form submission notifications in your Netlify site settings.
